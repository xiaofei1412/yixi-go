01 / A complete study loop

A review is only the beginning.

Play or import an SGF, save key positions and try your own move before revealing the lines. Notes, manual tags and scheduled reviews connect each session.

REVIEW

Explore without losing the game

Review candidate moves and score trends. Explore branches while preserving the original record; import and export SGF.

PRACTICE

Think first, reveal later

Save a key move as a practice position. Constrained search checks your answer, so other moves close to the reference can pass too.

COMPARE

Compare three lines together

Step through the recorded line, your retry and the engine recommendation in sync. Inspect board differences and capture your own reasoning.

03 / Start on your own computer

Extract. Open. Play your next game.

  1. Download and fully extract the ~279 MiB Windows ZIP.
  2. Double-click YixiGo.exe. The local app opens in your browser.
  3. Play or import a game. Allow GPU tuning on the first analysis.

Python, KataGo and the model are included. This build requires an OpenCL GPU driver and has no CPU fallback. It is unsigned; SHA-256 checksums are provided with the release.

This is a static project page. Games, analysis and personal data run in the downloaded app. The app interface and detailed guides are currently in Chinese.

Your games stay on your computer.

The first launch creates an empty database. Each computer and Windows account keeps its own games and practice records, with no cloud sync.

Data folder: %LOCALAPPDATA%\YixiGo
Copies run by the same Windows account share data. The database is not additionally encrypted. Quit the app before copying this folder to back it up.
